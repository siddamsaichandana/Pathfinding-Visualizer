Pathfinding Visualizer using BFS, DFS, Dijkstra & A*

Overview

Pathfinding Visualizer is an interactive web application that demonstrates how different pathfinding algorithms find the shortest path between a start node and an end node. Users can create obstacles, select an algorithm, and visualize the traversal process in real time.

Features

- Interactive grid generation
- Start and end node visualization
- Obstacle (wall) creation and removal
- BFS (Breadth First Search) visualization
- DFS (Depth First Search) visualization
- Dijkstra's Algorithm visualization
- A* Algorithm visualization
- Shortest path highlighting
- Grid reset and clear functionality

Technologies Used

- HTML
- CSS
- JavaScript

Algorithms Implemented

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Dijkstra's Algorithm
- A* Search Algorithm

Learning Outcomes

This project helped in understanding graph traversal techniques, shortest path algorithms, data structures such as queues and stacks, DOM manipulation, event handling, and algorithm visualization using JavaScript.
